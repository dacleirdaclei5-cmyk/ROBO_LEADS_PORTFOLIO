
# 🤖 ROBO LEADS

## Automação profissional para geração de leads B2B

O **ROBO LEADS** é uma solução desenvolvida em Python para automatizar a pesquisa, coleta, organização, validação e seleção de potenciais clientes empresariais.

### 🚀 O que o robô faz

* 🔎 Pesquisa empresas por tipo e localização
* 📊 Coleta dados públicos
* 🧹 Limpa e organiza os dados
* ✅ Valida os leads
* ♻️ Remove duplicados
* 📧 Pesquisa emails públicos nos websites
* 🔄 Faz nova validação após atualização
* ⭐ Calcula um Score de qualidade
* 🎯 Seleciona a quantidade solicitada
* 📑 Exporta os resultados para Excel

### 📋 Dados entregues

* Nome da empresa
* Website
* Email público encontrado
* Telefone
* Localização
* Setor
* Fonte
* Score
* Status
* Avisos
* Erros

### 🔄 Fluxo

```text
Pedido do cliente
       ↓
Pesquisa de empresas
       ↓
Coleta de dados
       ↓
Limpeza
       ↓
Validação
       ↓
Remoção de duplicados
       ↓
Busca de emails públicos
       ↓
Nova validação
       ↓
Score de qualidade
       ↓
Seleção dos leads
       ↓
Exportação para Excel
```
